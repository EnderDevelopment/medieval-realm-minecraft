# Medieval Realm

Medieval Realm is a Minecraft Bedrock Edition plugin that transforms your world into a medieval realm. It introduces a unique king, intelligent NPCs, and automatic construction systems to create a dynamic and immersive medieval experience. The plugin is designed to work with existing worlds and maps, preserving your original constructions, chests, and buildings. It features a monarchy system, human guards, intelligent inhabitants, and automatic construction, all managed through intuitive menus.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock Edition server.
3. Start or restart your server.

## Use

1. Join the server and use the `/ciao` command to greet the console.
2. To become the king, use the `/king` command.
3. Use the `/guard` command to manage human guards.
4. Use the `/inhabitant` command to manage intelligent inhabitants.
5. Use the `/build` command to access the automatic construction system.
